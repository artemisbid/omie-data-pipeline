# Supabase

Esta pasta contém migrations versionadas do schema do pipeline.

A migration inicial cria:

- `pipeline_runs`
- `pipeline_rejections`
- `pipeline_checkpoints`
- `omie_customers`
- `omie_services`

A CLI do Supabase ainda não está instalada neste ambiente. Antes de aplicar a migration no projeto remoto, revise o SQL e execute os comandos da CLI no ambiente local autenticado.

Nenhuma migration foi aplicada remotamente por esta etapa.
